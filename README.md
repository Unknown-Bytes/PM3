# PM3 — Tratamento e Preparação de Dados Netflix

## Sobre o Projeto

Este projeto tem como objetivo realizar o tratamento, limpeza, transformação e preparação de uma base de dados da Netflix contendo inconsistências reais e simuladas de qualidade de dados.

O foco principal do projeto é demonstrar o processo completo de preparação de dados para uso em:

- Business Intelligence (BI)
- Data Mining
- Análise Exploratória de Dados (EDA)
- Processos analíticos e DataOps

---

## Objetivos

- Diagnosticar problemas de qualidade de dados
- Corrigir inconsistências estruturais
- Tratar valores ausentes
- Padronizar categorias e textos
- Corrigir tipos de dados
- Realizar Feature Engineering
- Aplicar discretização e normalização
- Produzir um dataset final confiável
- Documentar todo o pipeline de tratamento

---

## Principais Problemas da Base

A base contém problemas simulando cenários reais de dados:

- Valores ausentes
- Placeholders inválidos
- Duplicidades
- Near duplicates
- Espaços extras
- Categorias inconsistentes
- Tipos incorretos
- Datas inválidas
- Inconsistências lógicas
- Corrupção textual
